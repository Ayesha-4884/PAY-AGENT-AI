ABOUT THIS PROTOTYPE

What is working here?

Buyer agent: a local negotiation engine extracts a price request, applies member and quantity discounts, and returns an offer or counter-offer.

Merchant shield: an explainable risk engine scores each checkout using order value, device, location and velocity signals. High-risk orders enter a review queue.

Payments: mock mode records a simulated checkout with no money movement. Optional PayPal Sandbox mode creates and captures sandbox orders using server-side API credentials.

This is a functional hackathon prototype, not production payment, fraud, chargeback or legal-compliance software.
